# Sources

- Noor Shaker, Julian Togelius, Mark J. Nelson, "Procedural Content Generation in Games" (Springer, 2016), ch. 1 "Introduction" §1.6.2, §1.6.5, §1.6.6 - https://pcgbook.com/chapter01.pdf - supports: necessary content must always be correct and optional content need not be; deterministic PCG regenerates the same content from the same starting point and parameters; generate-and-test alternates generating and testing in a loop until a satisfactory result - checked 2026-11-14
- Shaker, Togelius, Nelson, "Procedural Content Generation in Games", ch. 3 "Constructive generation methods for dungeons and levels" §3.2, §3.4, §3.7 - https://pcgbook.com/chapter03.pdf - supports: BSP guarantees no overlapping rooms and a structured dungeon; BSP partitions can theme room groups and lock a wing behind a key; cellular automata parameters each affect several map features, so a map with a given room count cannot be requested; Spelunky builds levels from a 4 by 4 grid of rooms chosen from predefined templates; Mario passes limit gap width to the jump range to guarantee playability - checked 2026-11-14
- Shaker, Togelius, Nelson, "Procedural Content Generation in Games", ch. 4 "Fractals, noise and agents" - https://pcgbook.com/chapter04.pdf - supports: filling a heightmap with independent random values gives spikes, not terrain; terrain needs several scales, built by scaling noise layers by the inverse of their frequency (1/f noise) - checked 2026-11-14
- Shaker, Togelius, Nelson, "Procedural Content Generation in Games", ch. 5 "Grammars and L-systems" §5.5 - https://pcgbook.com/chapter05.pdf - supports: a mission (what the player does) and a space (geometry) are two structures that grammars can generate - checked 2026-11-14
- Shaker, Togelius, Nelson, "Procedural Content Generation in Games", ch. 8 "Answer set programming" §8.5 - https://pcgbook.com/chapter08.pdf - supports: generate a reference solution along with the level; a map that contains a valid reference solution is proved solvable by existence - checked 2026-11-14
- Shaker, Togelius, Nelson, "Procedural Content Generation in Games", ch. 12 "Evaluating content generators" - https://pcgbook.com/chapter12.pdf - supports: expressive range is the space of levels a generator can make, plotted as a heatmap over chosen metrics to reveal bias and, across parameter sets, controllability - checked 2026-11-14
- Shaker, Togelius, Nelson, "Procedural Content Generation in Games", Appendix A interviews (Tarn Adams) - https://pcgbook.com/interviews.pdf - supports: advice not to simulate more detail than you need to get your point across - checked 2026-11-14
- Shaker, Togelius, Nelson, "Procedural Content Generation in Games" (Springer, 2016), publisher record - https://doi.org/10.1007/978-3-319-42716-4 - supports: bibliographic record for the book - checked 2026-11-14
- Maxim Gumin, "WaveFunctionCollapse" (GitHub repository) - https://github.com/mxgmn/WaveFunctionCollapse - supports: output contains only the NxN patterns present in the input; propagation can reach a contradiction when every option for a pixel is removed, and this happens rarely in practice - checked 2026-11-14
- MDN Web Docs, "Math.random()" - https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random - supports: the implementation selects the initial seed and it cannot be chosen or reset by the user - checked 2026-11-14
- Innes McKendrick, "Continuous World Generation in 'No Man's Sky'" (GDC 2017) - https://gdcvault.com/play/1024265/Continuous-World-Generation-in-No - supports: the talk describes the technical architecture of No Man's Sky's planet generation, from voxel-based generation through polygonization and texturing to population and simulation - checked 2026-11-14
