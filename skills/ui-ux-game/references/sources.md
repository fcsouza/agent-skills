# Sources for ui-ux-game

- Celia Hodent, "The Gamer's Brain, part 2: UX of Onboarding and Player Engagement" (GDC 2016, celiahodent.com) - https://celiahodent.com/gamers-brain-ux-onboarding/ - supports: three items at most in learning mode; give the why; never punish while learning; false cognitive affordances mislead; tutorial text on loading screens is not remembered well - checked 2026-11-14
- Celia Hodent, "Understanding the Success of Fortnite: A UX & Psychology Perspective" (celiahodent.com) - https://celiahodent.com/understanding-the-success-of-fortnite-ux/ - supports: the seven usability pillars, adapted from Nielsen's heuristics - checked 2026-11-14
- Jakob Nielsen, "Response Times: The 3 Important Limits" (Nielsen Norman Group) - https://www.nngroup.com/articles/response-times-3-important-limits/ - supports: 0.1 s feels instantaneous, 1 s keeps flow of thought, 10 s keeps attention (general interface research, not games) - checked 2026-11-14
- Steve Swink, Game Feel: A Game Designer's Guide to Virtual Sensation (Morgan Kaufmann/Elsevier, 2009), ch. 2 "The Computer Side of Things" - https://www.routledge.com/Game-Feel-A-Game-Designers-Guide-to-Virtual-Sensation/Swink/p/book/9780123743282 - supports: input response within about 100 ms, 50 ms reads as instant; same-frame feedback for causality - checked 2026-11-14
- Jesse Schell, The Art of Game Design: A Book of Lenses (Morgan Kaufmann, 1st ed., 2008), ch. 13 - https://shop.elsevier.com/books/the-art-of-game-design/schell/978-0-12-369496-6 - supports: ask what players need to know and want to know and what feedback conveys it; show mode changes in more than one way; keep overlapping modes on different input channels - checked 2026-11-14
- W3C, "Web Content Accessibility Guidelines (WCAG) 2.2" - https://www.w3.org/TR/WCAG22/ - supports: contrast 4.5:1 normal text and 3:1 large text (1.4.3); text resizable to 200 percent (1.4.4); target size 44 by 44 CSS px at AAA (2.5.5) and 24 by 24 at AA (2.5.8) - checked 2026-11-14
- Game Accessibility Guidelines, "Full list" - https://gameaccessibilityguidelines.com/full-list/ - supports: every item in templates/accessibility-checklist.md that is not a WCAG item - checked 2026-11-14
- Blake Crosley, "Design Philosophy: Fumito Ueda" (secondary source) - https://blakecrosley.com/blog/design-philosophy-fumito-ueda - supports: ICO has no health bars, score or map; the player holds R1 to grip the companion's hand - checked 2026-11-14
- Shigeru Miyamoto interview, A.V. Club (secondary source) - https://www.avclub.com/shigeru-miyamoto-explains-the-making-of-super-mario-bro-1798284041 - supports: World 1-1's blocks, goombas and pipes were placed to guide players through learning - checked 2026-11-14
