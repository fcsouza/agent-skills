## Webhooks

- Nuvemshop, "Webhook" (nuvemshop.dev, 2026) - https://nuvemshop.dev/en-US/api/resources/2025-03/webhook.md - supports: "Webhooks created through the API can be verified" (the docs do not say the Portal-set privacy webhooks are signed); header `x-linkedstore-hmac-sha256`; signature generated with the app secret and the request data; verification needs the Partner app `client_secret`, not the `access_token`; keep the secret on the server; compute the HMAC over the original body before parsing; some frameworks rename the header to `HTTP_X_LINKEDSTORE_HMAC_SHA256`; PHP example compares `hash_hmac('sha256', $data, APP_SECRET)` (lowercase hex) - checked 2026-11-15
- Nuvemshop, "Webhook, Retry policies" (nuvemshop.dev, 2026) - https://nuvemshop.dev/en-US/api/resources/2025-03/webhook.md - supports: 2XX expected, 3 second timeout; first 4 retries immediately after timeout and at about 5, 10, 15 minutes; then exponential backoff times 1.4 within 48 hours, up to 16 attempts; a success code stops notifications - checked 2026-11-15
- Nuvemshop, "Webhook, ordering and idempotency" (nuvemshop.dev, 2026) - https://nuvemshop.dev/en-US/api/resources/2025-03/webhook.md - supports: order is not guaranteed; messages can repeat; idempotency is the integrator's job; identical bodies are unique, bodies differing only in retry data are duplicates; URL must be HTTPS and not localhost or a Nuvemshop domain; `app/uninstalled` deletes the app's webhooks for that store; `POST /webhooks`, `GET /webhooks`, `PUT /webhooks/{id}` exist - checked 2026-11-15
- This skill's rule: compare signatures in constant time (`crypto.timingSafeEqual`). The vendor's PHP example uses `==`. Tested in `templates/webhook-verify.ts` with a signature made by `openssl dgst -sha256 -hmac` - https://nodejs.org/api/crypto.html#cryptotimingsafeequala-b - supports: `timingSafeEqual` throws on unequal lengths, so lengths are checked first - checked 2026-11-15
