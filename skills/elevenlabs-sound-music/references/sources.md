# Sources

Each line: source, URL, what it supports, date checked.

## ElevenLabs

- ElevenLabs, "Models" (ElevenLabs docs, 2026) - https://elevenlabs.io/docs/overview/models - supports: current ids `eleven_text_to_sound_v3`, `music_v2_5`, `music_v2`, `eleven_multilingual_v2`, `eleven_flash_v2_5` (about 100 ms median latency), `eleven_ttv_v3` (Text to Voice); "The `music_v1` model is deprecated and will be removed on January 31, 2027. The `eleven_text_to_sound_v2` model is deprecated and will be removed on March 1, 2027"; Flash is recommended over Turbo "in all use cases"; Eleven v4 "is available via the Text to Dialogue API"; Multilingual v2 suits "Character Voiceovers" - checked 2026-11-14
- ElevenLabs, "Create speech" API reference (ElevenLabs docs, 2026) - https://elevenlabs.io/docs/api-reference/text-to-speech/convert - supports: `model_id` defaults to `eleven_multilingual_v2`; `seed` is best effort, "Determinism is not guaranteed"; default output `mp3_44100_128`; the output format list has no Ogg format - checked 2026-11-14
- ElevenLabs, "Create sound effect" API reference (ElevenLabs docs, 2026) - https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert - supports: `duration_seconds` "Must be at least 0.5 and at most 30"; `loop` creates "a sound effect that loops smoothly"; `prompt_influence` 0 to 1, default 0.3; `model_id` default `eleven_text_to_sound_v2`, allowed `eleven_text_to_sound_v3` - checked 2026-11-14
- ElevenLabs, "Sound effects" capability page (ElevenLabs docs, 2026) - https://elevenlabs.io/docs/overview/capabilities/sound-effects - supports: SFX v3 prompting by action, setting and atmosphere; multi-event prompts such as "Sword being drawn, then clashing with another blade" - checked 2026-11-14
- ElevenLabs, "Compose music" API reference (ElevenLabs docs, 2026) - https://elevenlabs.io/docs/api-reference/music/compose - supports: `music_length_ms` "Must be between 3000ms and 600000ms"; `model_id` default `music_v1`; `seed` "Cannot be used in conjunction with prompt"; `force_instrumental` "guarantees that the generated song will be instrumental" and "Can only be used with `prompt`" - checked 2026-11-14
- ElevenLabs, "Create composition plan" API reference (ElevenLabs docs, 2026) - https://elevenlabs.io/docs/api-reference/music/create-composition-plan - supports: the plan endpoint "does not cost any credits but is subject to rate limiting"; `model_id` default `music_v1`, allowed `music_v2_5` - checked 2026-11-14
- ElevenLabs, "Music quickstart" (ElevenLabs docs, 2026) - https://elevenlabs.io/docs/eleven-api/guides/cookbooks/music - supports: "The Music API is only available to paid users"; store the key "as a managed secret"; `music.compose`, `music.compositionPlan.create`, `modelId: "music_v2_5"`; naming a band or musician returns `bad_prompt` with a suggested prompt - checked 2026-11-14
- ElevenLabs, "Best practices" for Music (ElevenLabs docs, 2026) - https://elevenlabs.io/docs/overview/capabilities/music/best-practices - supports: a prompt answers genre, mood, instrumentation, tempo and production era, and open questions get "the most average" choice; loop prompts state bars, BPM, key and what is excluded - checked 2026-11-14
- ElevenLabs, `@elevenlabs/elevenlabs-js` 2.78.0 published types (read in the installed package; the compose request type also fetched from unpkg) - https://unpkg.com/@elevenlabs/elevenlabs-js@2.78.0/api/resources/music/client/requests/BodyComposeMusicV1MusicPost.d.ts - supports: `textToSpeech.convert(voiceId, request)`, `textToSoundEffects.convert`, `music.compose`, `music.compositionPlan.create` return the shapes the boilerplate uses; `SfxModelId` and `MusicModelId` unions; the client reads `ELEVENLABS_API_KEY` by default - checked 2026-11-14
- ElevenLabs, official agent skills repository - https://github.com/elevenlabs/skills - supports: `text-to-speech`, `sound-effects` and `music` skills exist - checked 2026-11-14

## Google Lyria

- Google Cloud, "Lyria API" reference (Gemini Enterprise Agent Platform docs, 2026) - https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/lyria-music-generation - supports: model `lyria-002` via `publishers/google/models/lyria-002:predict` on `us-central1-aiplatform.googleapis.com`; `seed` "Cannot be used with sample_count in the same request"; `negative_prompt` example "vocals, slow tempo"; response field `predictions[].audioContent` (the official Lyria 2 notebook, https://github.com/GoogleCloudPlatform/generative-ai/blob/main/audio/music/getting-started/lyria2_music_generation.ipynb, decodes `bytesBase64Encoded` instead, so the boilerplate reads both); "Each generated audio clip is 30 seconds long and provided as a WAV audio file at a 48kHz sample rate"; instrumental only. The old path https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/lyria returns 404; the vertex-ai path redirects here (301) - checked 2026-11-14
- Google Cloud, "Lyria 2" model page (Gemini Enterprise Agent Platform docs, 2026) - https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/lyria/lyria-002 - supports: launch stage GA; maximum clip length 32.8 seconds; maximum 4 clips per prompt; 48 kHz `audio/wav`; prompts in US English; vocal generation not supported - checked 2026-11-14
- Google Cloud, "Lyria 3" model page (Gemini Enterprise Agent Platform docs, 2026) - https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/lyria/lyria-3 - supports: `lyria-3-pro-preview` (184 s maximum, vocals, `audio/mp3`) and `lyria-3-clip-preview` (30 s), launch stage Preview, released 2026-03-25 - checked 2026-11-14
- Google Cloud, "Generate music with Lyria" (Gemini Enterprise Agent Platform docs, 2026) - https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/music/generate-music - supports: Lyria 3 uses `POST .../locations/global/interactions`; Lyria 2 uses the predict method; "Each clip is 32.8 seconds long" - checked 2026-11-14
- Google Cloud, Vertex AI REST reference (2026) - https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/rest - supports: `v1.projects.locations.publishers.models` has a `predict` method, "Perform an online inference" - checked 2026-11-14
- Google Cloud, `@google-cloud/aiplatform` 7.8.0 published types - https://unpkg.com/@google-cloud/aiplatform@7.8.0/build/src/v1/prediction_service_client.d.ts - supports: `PredictionServiceClient.predict(request)` with `endpoint`, `instances` and `parameters` as `google.protobuf.IValue`; `apiEndpoint` client option; 7.8.0 is the npm `latest` tag (https://registry.npmjs.org/@google-cloud/aiplatform/latest) - checked 2026-11-14
- Google Cloud, "Set up Application Default Credentials" - https://docs.cloud.google.com/docs/authentication/provide-credentials-adc - supports: `gcloud auth application-default login` makes credentials "available to the Cloud Client Libraries" - checked 2026-11-14

## Browser playback

- MDN, "Autoplay guide for media and Web Audio APIs" - https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay - supports: media may autoplay once "The user has interacted with the site"; a rejected `play()` with `NotAllowedError` means autoplay was denied - checked 2026-11-14
- MDN, "User activation" - https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/User_activation - supports: activation-triggering events are `keydown`, `mousedown`, `pointerdown` (mouse), `pointerup` (non-mouse) and `touchend`; `touchstart` is not one - checked 2026-11-14
- MDN browser-compat-data, `HTMLMediaElement.volume` - https://github.com/mdn/browser-compat-data/blob/main/api/HTMLMediaElement.json - supports: Safari on iOS: "the value is always 1, and setting a value has no effect on the volume of the media object" - checked 2026-11-14
- MDN, "Web Audio API best practices" - https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices - supports: a context created outside a user gesture is `suspended` and is started with `resume()` after user interaction - checked 2026-11-14
- MDN, "AudioContext: resume() method" - https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/resume - supports: `resume()` resumes a suspended context and returns a Promise - checked 2026-11-14
